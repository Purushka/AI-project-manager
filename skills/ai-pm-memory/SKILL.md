# AI PM Memory - 跨项目记忆系统

## 触发场景

- 新项目启动时，检索历史项目中类似的架构模式
- 分解决策时，参考历史上类似节点的分解策略
- 合并方案完成后，将新发现的模式存入记忆库

## 工作流程

### 检索模式

1. **输入查询**：当前节点的超空间向量标签或自然语言描述
2. **向量检索**：在 project_patterns collection 中做 semantic search
3. **结构匹配**：在 tags 表中做集合运算匹配
4. **排序返回**：按相关性排序，返回 top-K 个历史模式

### 存储模式

1. **提取模式**：从完成的项目中提取可复用的架构模式
2. **生成描述**：用 LLM 生成模式的抽象描述（去除项目特定细节）
3. **向量化存储**：计算 embedding 并存入 project_patterns collection
4. **结构化索引**：提取结构化标签存入 tags 表

## 脚本

- `scripts/memory.py`：记忆存取逻辑

## 输入

- 查询：超空间向量标签 或 自然语言描述
- 存储：项目名称 + 节点 ID + 模式描述

## 输出

- 检索：历史模式列表（含相关性评分）
- 存储：确认信息
