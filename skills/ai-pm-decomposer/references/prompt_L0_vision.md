## 你的任务

请从以下维度分析这个产品 idea，输出一个完整的产品愿景文档：

1. **目标用户画像**：核心用户群体是谁？他们的痛点和需求是什么？
2. **核心价值主张**：产品解决什么问题？相比现有方案的差异化优势是什么？
3. **商业模式**：如何盈利？主要收入来源是什么？
4. **市场规模**：TAM/SAM/SOM 估算
5. **竞争格局**：主要竞品和差异化定位
6. **成功指标**：衡量产品成功的核心 KPI
7. **子系统初步划分**：将产品拆分为 5-8 个顶层子系统

## 输出格式

请输出以下 JSON 结构（包裹在 ```json ``` 中）：

```json
{
  "children": [
    {
      "title": "子系统名称",
      "description": "详细描述这个子系统的职责、边界和核心功能",
      "summary": "一句话概括",
      "vector": {
        "domain": ["所属功能域"],
        "entities": ["涉及的数据实体"],
        "patterns": ["可能用到的设计模式"],
        "api_shape": {
          "inputs": ["输入类型"],
          "outputs": ["输出类型"],
          "side_effects": ["副作用"]
        },
        "tech_traits": ["技术特征"],
        "actors": ["用户角色"],
        "nfr": ["非功能需求"],
        "rule_fingerprint": "核心业务规则一句话"
      }
    }
  ]
}
```

确保每个子系统的职责边界清晰，不重叠。优先识别可能被多个子系统共享的基础能力（如用户认证、通知服务）并将其作为独立子系统。
